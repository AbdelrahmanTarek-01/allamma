# اللمّة · Allamma

نادي ألعاب جماعية أونلاين ومجاني للصحاب، بيتلعب من الموبايل. أول لعبة: **مين الجاسوس؟**

| الفولدر | فيه إيه |
|---|---|
| `01-brainstorm/` | الفكرة، الألعاب، القرارات اللي اتاخدت، قواعد مين الجاسوس، أفكار لبعدين |
| `02-design/` | الهوية البصرية، ولينك كانفاس التصميم، وبروتوتايب حزّورة الأول |
| `03-code/` | الكود: `server` (NestJS + Socket.IO) و`client` (React + Vite)، وطريقة التشغيل في `README.md` |
| `04-docs/` | المعمارية، أحداث الـ Socket، الخطة الجاية |
| `05-deploy/` | دليل الرفع المجاني على Render، وملفات Docker لسيرفر بعدين |

## تشغيل سريع على جهازك
```bash
cd 03-code
npm run install:all
npm run dev:server    # في ترمينال
npm run dev:client    # في ترمينال تاني ← افتح http://localhost:5173
```
