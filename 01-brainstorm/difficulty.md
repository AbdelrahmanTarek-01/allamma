# Difficulty system — applies to EVERY game (built and future)

Levels (same names, same colours, same control in every game's host setup):
- سهل  (#3DDC97) — first-timers, relaxed
- متوسط (#4D9DFF) — DEFAULT
- صعب  (#FF8A3D) — experienced players
- ماكس (#FF4F9A) — no mercy + one "twist" rule

Rules:
- Host-only setting; others see a read-only chip (game name + level colour) in the room.
- Each level must change real gameplay: time, content difficulty, helpers, penalty for mistakes. Max adds one twist.
- Content (places, questions, words) must be tagged with difficulty 1-4 so the level picks the right pool.
- A new game is not "designed" until its 4-level table exists here.
